# 验收标准：默认站点星标切换

## AC1：表单中无 isDefault 开关
- **Given** 用户打开添加站点或编辑站点的 Modal
- **When** 查看表单内容
- **Then** 不应看到"设为默认站点"的 toggle 开关

## AC2：站点列表显示星标按钮
- **Given** 设置面板的站点列表中有站点
- **When** 查看每个站点卡片
- **Then** 每个站点卡片的编辑按钮左侧显示一个星标图标按钮

## AC3：默认站点星标高亮
- **Given** 某个站点已被设为默认
- **When** 查看站点列表
- **Then** 默认站点显示实心星标（高亮），其他站点显示空心星标（灰色）

## AC4：点击设为默认
- **Given** 站点列表中有多个站点，无默认站点
- **When** 用户点击某个站点的空心星标
- **Then** 该站点变为默认（星标变为实心高亮），设置自动保存

## AC5：点击取消默认
- **Given** 某个站点已是默认站点
- **When** 用户点击该站点的实心星标
- **Then** 该站点取消默认（星标变为空心灰色），设置自动保存

## AC6：互斥约束
- **Given** 站点 A 已是默认站点
- **When** 用户点击站点 B 的星标设为默认
- **Then** 站点 A 的星标变为空心，站点 B 的星标变为实心，同时只有一个站点为默认

## AC7：发布时默认选中
- **Given** 站点 A 已设为默认
- **When** 用户打开发布预览 Modal
- **Then** 站点下拉框默认选中站点 A

## AC8：无默认站点时回退
- **Given** 没有站点被设为默认
- **When** 用户打开发布预览 Modal
- **Then** 站点下拉框默认选中第一个站点

## AC9：Tooltip 提示正确
- **Given** 用户悬停在星标按钮上
- **When** 查看 tooltip
- **Then** 非默认站点显示"设为默认站点"，默认站点显示"取消默认站点"
